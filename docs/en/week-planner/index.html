How to use this lab

  1. Start with an ordinary recent week. Multiply nightly sleep by seven and round-trip travel time by travel days.
  2. Count each hour once. Learning during a commute can belong to the main activity rather than both categories.
  3. Leave a buffer before trying a small project. No unallocated time is not a failure; this map helps reveal constraints.
