Put a day milestone in your calendar: check before and after import

Life Counter editorial notes · Updated September 7, 2026 · 中文版

Understand all-day events, day zero and reminders so that a milestone does not arrive a day early or appear twice.

01 Choose the date you want to mark02 The download is an all-day event03 Choose reminders after importing04 What travels with the file

When does an all-day event end?

  1. Displayed date: 2028-02-29
  2. Exclusive end in the file: 2028-03-01
  3. The end date is excluded, so the event still occupies one day.

Check the date after importing, then set your reminder. Repeated imports may create duplicates.

Choose the date you want to mark

Enter a birthday in the milestone tool and check the reference date. The upper result is the next thousand-day milestone strictly after that reference. The custom field accepts another day count. Your birth date is day zero, so “10,000 days old” and an ordinal “10,000th day of life” may differ by a day.

For a January 1, 2000 birthday, 10,000 elapsed calendar days falls on May 19, 2027. Check the displayed date and count before exporting. You do not need to provide a birth time, location or calendar account.

The download is an all-day event

“Add to my calendar” creates an .ics file with the milestone date and day count, without directly including the entered birthday. It encodes an all-day calendar date rather than midnight in a named time zone, which suits a milestone intended to retain the same calendar date.

The file’s end date is the following day because iCalendar uses an exclusive end boundary. An all-day event on May 19 ends at the May 20 boundary; it does not span two celebration days. The website never writes to a calendar account on your behalf.

Choose reminders after importing

Open or import the file with an application that supports iCalendar. Entry points vary by device and application, and a browser may simply save the file to Downloads. In the import preview, look for one all-day event with the day count in its title.

The file contains no notification alarm. Set a reminder for the day before, the day itself, or none at all in your calendar application. Reimporting can be deduplicated by some applications and create duplicates in others. Check existing events rather than assuming an import will replace them.

What travels with the file

The file contains a date, day count, title and event identifier. Although it does not directly write a birthday, someone could subtract the count from the milestone to infer it. Decide whether to share the file accordingly.

If an imported date differs from the page, confirm that you imported the latest file and check whether the application converted an all-day date into a timed event. Reproduce any issue using fictional dates before emailing us. You do not need to send your calendar or personal records.
